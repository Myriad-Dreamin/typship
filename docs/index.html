          安装方法

          使用 Cargo 直接安装当前主线版本：
          cargo install --git https://github.com/Myriad-Dreamin/typship typship

          需要 Rust 1.85+（Edition 2024）。注：crates.io 上已发布的 typship 0.1.0–0.4.2 为早期旧线，当前基于 typship-pack 的重构版本尚未发布至 crates.io，请通过 --git 或源码安装。

          或克隆仓库本地构建与测试： 
          git clone https://github.com/Myriad-Dreamin/typship.git
cd typship
cargo build --release
cargo test --workspace
